# Guessing Game

**Language:** Python

**Description:** A simple console-based number guessing game. The program picks a secret number between 1 and 100, and the player tries to guess it. After each guess, the game gives a hint ("Too High" or "Too Low") until the correct number is found. Players can choose Easy mode (10 attempts) or Hard mode (5 attempts).

## How to Run

1. Make sure you have Python 3 installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   python guessing_game.py

5. Choose a difficulty level (Easy or Hard) and start guessing!
